# Resume Project Description

## One-Line Version

Built and deployed a retail analytics dashboard that transforms raw CSV transaction data into warehouse-modeled business insights using Java, interactive visualizations, and an AI business assistant.

## Short Resume Version

Developed a full-stack retail analytics dashboard in Java that reads raw retail sales data, builds fact and dimension tables, computes business KPIs, and serves an interactive web dashboard with filters, trend analysis, and an AI-driven business insights assistant. Deployed the application publicly using Docker and Render.

## Strong Resume Bullet Points

- Built a deployed retail analytics dashboard in Java that converts raw CSV transaction data into interactive business insights for sales, customers, cities, products, payment methods, and trends.
- Designed a warehouse-style data model with fact and dimension tables to support structured reporting and drill-down analysis.
- Implemented a dynamic AI business assistant that answers natural-language questions about performance, comparisons, trends, customer value, growth opportunities, and business risks.
- Developed interactive frontend features including KPI cards, trend drilldowns, top/bottom product analysis, contribution views, and downloadable data tables.
- Containerized and deployed the application using Docker and Render, making the dashboard publicly accessible as a live portfolio project.

## LinkedIn / Portfolio Description

Retail Analysis Dashboard is a live business intelligence web application that starts from raw retail sales CSV data and turns it into a full reporting experience. The project includes data ingestion, warehouse modeling, KPI generation, interactive visualizations, and a dynamic AI assistant that provides business-facing answers grounded in the dataset. It was built in Java and deployed publicly using Docker and Render.

## Interview Explanation

This project solves the problem of turning raw retail transaction data into something a business owner can actually use for decision-making. I built a Java application that reads the raw CSV, creates a warehouse-style reporting model, generates business metrics, and serves a dashboard through a web interface. I also added a dynamic AI business assistant so users can ask questions in natural language and get data-grounded insights. Finally, I containerized and deployed it so it runs as a live public application.
